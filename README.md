# 📉 Customer Churn Prediction

A machine learning project that predicts whether a telecom customer is likely to churn (leave the service) based on demographics, account information, and service usage behavior. Built using Python, scikit-learn, and the Telco Customer Churn dataset.

---

## 🚀 Features

- 🔍 Logistic Regression & Random Forest models
- 📊 Data cleaning, preprocessing, feature encoding
- 📈 Model evaluation (accuracy, precision, recall)
- 🧠 Predictive script for new customer churn
- 🧪 Ready for Streamlit/Flask deployment

---

## 🧠 Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn
- Joblib (for saving model)

---

## 📂 Dataset

This project uses the **Telco Customer Churn dataset** from Kaggle:

📎 [Download Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

### 📝 Details:

- 🧾 Records: 7,043 customers  
- 🎯 Target: `Churn` column (Yes/No)  
- 📊 Features:
  - Demographics: Gender, SeniorCitizen, Partner
  - Services: Internet, Phone, Streaming
  - Contract: Type, Tenure, MonthlyCharges, TotalCharges
